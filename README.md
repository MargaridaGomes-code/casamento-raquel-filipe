# Wedding Event Web 

This project is a mobile-optimized  designed to streamline guest interaction and photo sharing for a private event. 

## Purpose
The goal of this website is to provide a seamless way for guests to upload photos directly to a private Google Drive folder, ensuring privacy and data organization without the need for complex backend infrastructure.

## Features & Technologies
- **Data Integration:** Integrated with Google Forms API and Google Drive for secure, private file uploads.
- **Frontend:** Built with HTML5, CSS3 (including SVG animations for UI/UX), and JavaScript.
